## What shipped

- **Escalation ladder** (`runRoundInner`/`runObserver`): hidden read bounds
  shrink ×(1−0.15) per round past the first, floored at 1.2 s (round 2:
  2.13–7.65 s, round 3: 1.81–6.50 s). The 0.35 s lowering tell is untouched —
  the telegraph contract holds by construction and by test.
- **Suspicion** (`sweep`): a NEAR-CATCH = an eat window that closed after the
  paper began to drop but before the eyes opened (risky-but-unpunished — the
  only margin the FSM can already see). Room-wide count; each point shortens
  the next FULL read by 0.3 s (re-floored); at 2 the boss keeps the BossAngry
  atlas up for the round (`CanteenBoss.setSuspicious`, OR'd into setAngry;
  resets naturally — props rebuild per round).
- **Fake-lowers** (rounds ≥2): at most one theatrical `glance` (LookDown, no
  phase behind it) per hidden read, never two reads in a row, only in reads
  long enough that the glance lands a full RustleLead clear of the real tell.
  Bounds derived from RAISING_TIME + RustleLead + `CanteenBoss.GlanceSeconds`
  (exported constant). No boss rig → audio-only fake.
- **Hot peas** (rounds ≥2): 4 of 20 peas per plate seeded via `st.rng`, tinted
  `TrialKit.PALETTE.Hazard` amber (typeof-guarded pcall-require; hex fallback
  D9A036). Pea identity is deterministic (plates empty top-down, so the forked
  pea is `#remaining` pre-decrement). Forked hot peas must reach a mouth in 8 s
  or the MAIN ROUND LOOP voids them (fork −1, cpmiss nudge, cpstate push) — no
  task.delay timers, every window dies with the loop/death/cleanup by
  construction. A voided pea makes CLEAN PLATE unreachable for that player (by
  design: the price is the finished band).
- **Scoring — banked peas keep points:** PEA_STEP = Feel.Canteen.PeaScore (60,
  was 40). Bands: eliminated 0 + min(999, eaten×60 + survived×2); alive 1000 +
  min(999, eaten×60); finished 2000 + min(999, spare×10). DETAIL_CAP=999
  because 19×60=1140 would breach a band with the live 20-pea plate — bands
  can never overlap; clamp flattens ordering only at 17+ eaten.
- **Settlement:** the FIRST clean plate arms `Pacing.Timing.CanteenSettlement`
  (5.0 s, new key) and announces `SETTLEMENT. 5 SECONDS_` as a feed line
  (never a card — MP-08 B-02); when it expires (no pending executions, nobody
  mid-finish) the round ends. The deadline + EXECUTION_GRACE cap still rules:
  settlement only ever SHORTENS a round (worst case ~78 s < watchdog 95 s).
- **Last diner:** exactly one living plate still holding food (never solo
  seatings) → one `MachineVoice.pick("lastdiner")` feed line. New voice
  category with 4 lines (`ONE REMAINS_` etc.), pool rules verified by
  tests/voice.lua (now asserts seven categories).
- **Rustle tell:** `props.rustle()` exactly 0.35 s before every lowering onset
  (after the execution wait, so the gap never stretches) AND before every fake
  glance — deliberately, so the sound never disambiguates them. One Sound on
  the boss root, CRT-hum pattern: `SoundService.KenopsiaAudio.SFX.Canteen.
  Rustle` created live with empty SoundId (silent + one warn until the audio
  phase pastes the id — zero code change then).
- **Dead diners:** verified NO change needed — canteen has no death-camera
  switch; eliminated players keep the fixed ObserverCamera table view.
- **KenopsiaClient: zero changes.** All feedback rides pre-existing kinds
  (cpstate/cpmiss/cpobs/cpdone/cpend/feed) and server-part visuals; feed lines
  without `style` render phosphor per MP-08.
