# Performance pass 1 (22.08.2026)

Source: a four-reader static audit of `studio-src` (server framework, server trials, client
monolith, client support), 45 findings; the adversarial verify stage died on a session limit,
so the triage below is by hand. Target device: mid-range Android at 60 fps, server tick < 4 ms
at 4 players.

## Triage of the rest (not done, ordered by value)

**Worth doing before P4 ships trials**
* `TrialKit.Round:sample` rebuilds `livingOf()` per call in the 20 Hz tick; `Minefield` does the same (line ~779) plus a string key concat per runner per tick → snapshot subjects at GO, numeric cell keys.
* `TrialKit.wireInput`: one `OnServerEvent` per trial on the shared `TrialInput` remote (15 handlers per packet) → one dispatcher keyed by trialId.
* `MachineFlow.runRoundGuarded` `task.cancel` skips `TrialKit` round cleanup (runtime folder, registries, teardown fns leak per timed-out round) → `TrialKit.abortRound`.
* `BloodFX.ev()` without recipients falls to `FireAllClients`; `Round:kill` passes none → pass the room audience.
* `CanteenProps` fork flight + observer loops at `task.wait()` (60 Hz server) → weld tines/riders, step at 20 Hz.
* `Minefield` compactor: now a single `PivotTo` of the 18-part FBX model at 20 Hz (replicates 18 CFrames per tick) → move it on the client from a z value, or weld to one root part.
* `BirdHunting` turret aim thread re-pivots every 60 ms even when unchanged; four Humanoid writes per runner every 0.2 s → cache `Barrel`, skip unchanged, write once.
* `KenopsiaClient` score-screen marquee, `screenBlood` and `Selection` flicker all animate inside `KenopsiaMachine` → move into the overlay / pool the droplet frames / cache tile descendants.
* `MachineLayout.apply()` unthrottled on every `ViewportSize` change → coalesce with `task.defer`.
* `GoreClient.refreshRayFilter()` rebuilt every Heartbeat while droplets live → rebuild on character/player events only.
