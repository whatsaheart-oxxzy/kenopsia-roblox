## Roulette crosshair

The tile centre is an absolute screen point, but `CrossH`/`CrossV` live inside `Selection`, which MachineLayout scales (UIScale 0.81 on desktop): the old code applied the absolute offset as a local one, so the lines landed 0.81× too high/left (+16 px fudge). Now converted into Selection's own pixel space.
Measured after the snap tween: tile2 centre (634, 230), CrossV.x 632, CrossH.y 228 → **dx −2.4 px, dy −2.4 px** (before: ~59 px high).

## Platform detection

`detectPlatform()` composes `TouchEnabled / MouseEnabled / KeyboardEnabled / GamepadEnabled` with the viewport: gamepad-only → Console; touch with short axis < 500 → Mobile; touch with aspect < 1.6 → Tablet (iPad 4:3), else by short axis. Scale clamps: Mobile 0.55–0.85 (was 0.42), Tablet 0.7–1.0 (new), Desktop/Console unchanged. Tablet uses the Mobile controls text. `ForcePlatform` accepts "Tablet".
