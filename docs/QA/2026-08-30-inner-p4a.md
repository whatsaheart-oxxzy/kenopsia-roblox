## What shipped (no visible change until 4b — the client renders none of it)

- **`Services/Profiles.luau`** (NEW, ~390 lines, hand-rolled — not the
  community package): volatile-first persistence. Every player gets an
  in-memory `ProgressionRules.defaultProfile()` synchronously at join; the
  DataStore (`KenopsiaProfile_v1`, key `u_<UserId>`) upgrades it in the
  background — UpdateAsync-only with a `{jobId, ts}` session lock (stealable
  after 180s), 3 attempts with backoff, and on failure the player stays
  VOLATILE: fully playable, nothing written (Studio-without-API is this path,
  one warn). Writes at EXACTLY three moments: verdict flush (fire-and-forget,
  race-guarded vs leave), PlayerRemoving (write + lock release), and the
  codebase's first `BindToClose` (parallel, capped 25s < the 30s budget,
  instant when volatile). Merge discipline: OWNED_FIELDS only, unknown/future
  fields preserved; migrate fills missing keys, never downgrades
  schemaVersion; firstSeen set once. On load: `profilestate` packet (dark —
  unknown kind renders nothing), fresh attributes KenopsiaClearance/
  KenopsiaStreak (census-clean), funnel step 1, and — returning non-volatile
  players only, ≥8s post-join (clears the content-warning hold) — a greeting
  on the existing `announce` kind: `SHIFT <n>. WELCOME BACK_` / live streak:
  `NIGHT <n> CONSECUTIVE. NOTED_` (fixed-format from Profiles, NOT a
  MachineVoice pool — pick's placeholder contract is {name, dir} and the
  greeting needs numbers; revisit in 4b if numeric placeholders prove legal).
  Dormant Phase 5 socket: `Profiles.grantEmote`.
- **`Shared/Rules/ProgressionRules.luau`** (NEW, pure Lua 5.1 — the Pacing
  discipline): the ONE place the profile shape lives. XP table (survived 25 /
  round won 40 / trial won 60 / VIABLE 150 / REJECTED 50 / daily first 200),
  CLEARANCE bands (PROBATIONARY 0 → GRADE_D 500 → C 1500 → B 3500 → A 7000 →
  OVERSEER_CANDIDATE 14000), `tickStreak` (dayStamp passed in — no clock in
  the pure file; shield earned at each multiple of 7, capped at 1, covers
  exactly one missed day, survives a reset; same-day idempotent, stale ticks
  ignored), QuestPool (8 quests, all metrics countable from the three shipped
  trials, dormant until a later phase), `rollQuests` (deterministic day-seeded
  LCG, injectable rng, 3 distinct slots).
- **MachineFlow wiring (7 additive hunks, 61 lines, 0 removed):** requires;
